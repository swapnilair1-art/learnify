# Brand Guidelines — Integration Notes

This document summarizes how the UI tokens, spacing, and motion systems map to the design system.

- Primary colors: use `focus-blue`, `calm-slate`, `cognitive-white`, `accent-teal`, `warning-gold`.
- Card system: use rounded corners, subtle shadows, soft elevation.
- Typography: use Inter or a system sans family. Keep generous line-height.

See the root `brand_guidelines.md` for full guidance.
